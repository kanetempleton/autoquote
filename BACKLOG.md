# Product Backlog – AutoQuote

## User Stories

1. As a user, I want to submit my age, vehicle year, and ZIP code so that I can receive an insurance quote.
2. As a user, I want to see a clear quote result (premium + quote ID) after submitting the form.
3. As a QA engineer, I want reliable API tests for creating and retrieving quotes so that the backend is verified independently.
4. As a QA engineer, I want end-to-end UI tests using Page Objects so that the form flow is covered and maintainable.
5. As a team, we want the full test suite to run automatically on every pull request so that broken code cannot be merged.
