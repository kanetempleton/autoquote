# AutoQuote – Test Automation Framework

Insurance quote simulator for using test automation framework and best practices using Ruby.


## Running the app:

```
ruby app/app.rb
```
or use the run script:
```
./run.sh
```

## Running the tests

### Run all RSpec tests
```
bundle exec rspec -f d
```

### Run all Cucumber features
```
bundle exec cucumber
```

or run all tests using the test script:
```
./run_tests.sh
```
